## Nachweise

- HeartGold-Codezuordnungen: strukturierte Dateien mit Quellpfad, Commit und Status.
- Visuelle Befunde: Asset-/Move-ID, Versionsbezug, reproduzierbarer Test und zulässiger Screenshot/Frame.
- Build/Regression: Quellstand, Befehl, Umgebung und Ergebnis.
- Änderungen: Changelog/PR mit Verweisen auf QA-Nachweise.

Keine Datei als geprüft/getestet markieren, solange der Nachweis fehlt. Keine vollständigen ROMs oder Spielstände ablegen.
